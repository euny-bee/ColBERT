## 4. Logistic Fitting

### 모델
```
log10(Ids) = B + L / (1 + exp(-K * (Vgs - V0)))   [전체 구간 fit]
Ids = logistic(VSAT) + (Vgs - VSAT) * SLOPE        [Vgs >= VSAT 선형 연장]
```

- V0 = Vth (logistic 변곡점)
- VSAT: Ion의 90% 도달 지점
- SS = 4000 / (L × K)  mV/dec

## 6. Phase 3 (L2 search) Python 모델 — 변수 정의

### 실제 회로 변수

| 변수 | 의미 | 값 (예시) |
|------|------|-----------|
| V2 | 저장된 데이터 전압 (electrical) | -1.0V |
| -V2 = neg_V2 | Phase 2 M0 source line | +1.0V |
| V1 | Phase 3 query 전압 (sweep) | -1 ~ +2V |
| VDD | Phase 3 source line | 1.0V |
| VML | Match line | 0V |

### VSN 수식 (핵심)

```
M0: VSN0 = V1 + V2 + Vth = V1 + (-1.0) + 0.151 = V1 - 0.849
M3: VSN3 = -V2 + Vth - V1 = 1.0 + 0.151 - V1 = 1.151 - V1
```

- Crossover: V1 = -V2 = neg_V2
- 전류: I_total ∝ |V1 + V2|  (= |V1 - 데이터값|)

### 양방향 전류 모델

```python
def I_M0(v1):
    Vgd = v1 + V0 - neg_V2      # = VSN0
    Vgs = Vgd - VDD
    return max(I_single(Vgd) - I_single(Vgs), 0)

def I_M3(v1):
    Vgd = neg_V2 + V0 - v1      # = VSN3
    Vgs = Vgd - VDD              # ← 범용 수식 (neg_V2=VDD 가정 금지)
    return max(I_single(Vgd) - I_single(Vgs), 0)
```

> **버그 수정 이력**: 초기 M3 코드에서 `Vgs = V0 - v1` 로 하드코딩 →
> `neg_V2 = VDD = 1.0V` 일 때만 우연히 맞는 공식이었음.
> V2=0V 등 일반 케이스에서 Vgd=Vgs → I=0 오류.
> `Vgs = Vgd - VDD` 로 수정하여 모든 V2에 범용 적용.

## 9. Phase 2 VSN Settling 시뮬레이션

### 회로 (사용자 제공 다이어그램 기준)

```
M1: gate=V3=3V, source=SN (pass transistor)
M0: gate=SN, source=V_BL0=-1V (diode-connected via M1)
C:  SN(top) ↔ V_SL0=0V(bottom), C=100fF
SN initial = 3V
```

### ODE 모델

```python
# bidirectional 모델 (Vgd=0, diode-connected)
I_net = I_single(Vgs=SN-V_BL0, V0) - I_single(Vgd=0, V0)
dVSN/dt = -max(I_net, 0) / C    # 역방향 전류 차단 → V_BL0 클램프
```

### 결과 (`phase2_VSN_settling_vthshift.png`)

| Vth | VSN 수렴값 | 비고 |
|-----|-----------|------|
| +0.65V (+0.5 shift) | **-0.35V** = V_BL0 + Vth | 느린 정착 |
| +0.15V (원래) | **-0.85V** = V_BL0 + Vth | 중간 |
| -0.35V (-0.5 shift) | **-1.0V** = V_BL0 (클램프) | 빠른 정착, 바닥에서 멈춤 |

> **클램프 원리**: SN < V_BL0이면 Vds < 0 → 역방향 전류 → 실제로 SN은 V_BL0=-1V 이하로 내려갈 수 없음.
> VSN_eq = max(V_BL0 + Vth, V_BL0) = V_BL0 + max(Vth, 0)
