## 1. 회로 이해: 3-Phase 동작

### Phase 1 — Pre-charge
- VCOMP = 3V, VREAD = 3V, VML = 0V
- 모든 노드를 VPRE로 초기화 (리셋)

### Phase 2 — Data Store + Vth Compensation
- VCOMP = 3V, VREAD = -3V, VML = 0V
- 비트라인에 ±V1 인가 → M0가 꺼지는 순간까지 VSN 방전
- **Vth 보상 원리**: VSN = -V1 + Vth,  VSN_bar = V1 + Vth
- 트랜지스터별 Vth 편차가 저장값에 자동으로 포함됨

### Phase 3 — L2 Search
- VCOMP = -3V, VREAD = 3V, VML = 0V, VDD = 1.7V
- VSL0 = V2 (쿼리 전압) 인가 → 캐패시티브 커플링으로 VSN 이동
- VSN = V2 - V1 + Vth = 2V2 + Vth  (V2 = -V1 조건)
- VGS_M0 = VSN = 2V2 + Vth
- **도통 조건**:
  - V2 > V1 → M0 ON: I_M0 ∝ (V2 + Vth - V1) - Vth = V2 - V1
  - V1 > V2 → M3 ON: I_M3 ∝ (V1 + Vth - V2) - Vth = V1 - V2
- M0 source = 0V, drain = VDD = 1.7V

## 2. die4 Logistic 모델 파라미터

**파일**: `IGZO_TR [die4_ovl20_R0(20) ; 5_6_2026 6_08_20 PM].csv`
**조건**: VDS = 1V, VGS sweep -3V ~ 3V

**모델**: `log10(IDS) = B + L / (1 + exp(-K * (VGS - V0)))`

| 파라미터 | 값 |
|---|---|
| L | 6.112020 |
| K | 2.731949 |
| V0 (Vth) | 0.151045 V |
| B | -10.713911 |
| VSAT | 2.880 V |

**VDS 보정 (1V → 1.7V)**: MOSFET linear/saturation 모델 적용
- VoD < VDS: saturation → IDS ∝ VoD²/2 (VDS 무관)
- VoD > VDS: linear → IDS ∝ VoD·VDS - VDS²/2

## 3. 그래프 1: Phase 3 L2 Search (VDS = 1V vs 1.7V)

**파일**: `plot_phase3_L2_die4.py` → `plot_phase3_L2_die4.png`

**조건**:
- V2 = -V1, V2 ∈ [-1V, 1V], step 0.05V
- x축: V2 - V1 = 2V2 ∈ [-2V, 2V]
- VGS = |2V2| + Vth (보상 포함)

**결과**:
- |x| < 1V: VDS=1V, 1.7V 두 커브 동일 (둘 다 saturation)
- 1V < |x| < 1.7V: VDS=1.7V가 높음 (1V는 linear 진입)
- |x| > 1.7V: VDS=1.7V ~30% 높음
- x = ±2V에서: VDS=1V → ~24 μA, VDS=1.7V → ~31 μA

## 4. 그래프 2: Vth Compensation 효과 비교 (A vs C)

**파일**: `plot_AC_vth_comparison.py` → `plot_AC_vth_comparison.png`

**Vth 값 5종** (die4 원본 + shift):

| 커브 | Vth |
|---|---|
| 원본 | 0.151 V |
| +0.1V | 0.251 V |
| +0.2V | 0.351 V |
| +0.5V | 0.651 V |
| +1.0V | 1.151 V |

### Option A — With Vth Compensation
- VSN = V2 - V1 + Vth_new (보상 회로가 새 Vth 자동 추적)
- VGS = |2V2| + Vth_new, 모델 V0 = Vth_new
- **VGS - V0 = |2V2| → Vth에 무관**
- **결과: 5개 커브 완전 겹침 → 보상 완벽 동작**

### Option C — No Compensation
- VSN = V2 직접 인가 (데이터 저장 없음, V1 없음)
- VGS = |V2|, 모델 V0 = Vth_new
- 도통 조건: |V2| > Vth_new → dead zone = ±Vth_new
- **결과: Vth 증가할수록 dead zone 확대, 전류 감소**
  - Vth = 1.151V: dead zone ±1.151V → V2 ∈ [-2, 2]의 대부분이 OFF

### 핵심 결론
Vth 보상 회로(Phase 2)가 있으면 트랜지스터 Vth가 최대 +1.0V shift해도 출력 전류가 전혀 변하지 않음.
보상 없이는 Vth shift가 클수록 dead zone이 넓어져 거리 연산 정확도가 크게 저하됨.
